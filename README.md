# 🎠Carrossel de Imagens

O Carrossel de Imagens é uma aplicação que permite navegar entre diferentes imagens de forma interativa, utilizando controles para avançar e voltar entre os conteúdos.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
